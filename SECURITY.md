# Security reports

Send suspected vulnerabilities privately to **hello@silverz.net** with the affected version, a minimal reproduction and impact. Do not include secrets or disclose private browser/user data. Do not publish exploit details or personal data in a GitHub issue.

Only the latest published preview is currently intended for evaluation. There is no published long-term support schedule.

Download installers only from this repository's Releases and compare SHA-256 checksums. Payload integrity signatures are distinct from Windows Authenticode signing. Do not disable endpoint protection or browser safeguards as a troubleshooting step.
