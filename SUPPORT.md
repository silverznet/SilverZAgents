# Support

Product and commercial enquiries: **hello@silverz.net** · https://silverz.net

For reproducible bugs, open an issue and include:
- Application/extension versions and Windows version.
- Browser name/version and single-profile or multi-profile mode.
- Task type, run limits, prepared/online/offline mode (without keys).
- Steps to reproduce, expected behavior and actual result.
- A short sanitized error excerpt or screenshot with personal information removed.

Do not attach full logs, application databases, credentials, browser profiles, cookies, API keys or private post content. Keep enough context to reproduce the problem without identifying a person or exposing a private group. Never repeat a send solely to obtain a better screenshot.

For installation, consult [INSTALL.md](docs/INSTALL.md). For security issues, use [SECURITY.md](SECURITY.md) instead of a public issue. No guaranteed support response time is stated for this preview.
